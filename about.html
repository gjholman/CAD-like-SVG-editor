CAD-like SVG editor

Draw SVGs the way CAD sketches them.

Add relations and dimensions to lines, arcs and curves, and a solver keeps them consistent. Change one number and the drawing follows.

The editor is in development. Open the editor

Every line shows how pinned down it is

Under defined

Parts can still move. Drag them to see what's loose, then add a relation or dimension to fix them in place.

Fully defined

Every point is pinned by a relation or a dimension. Nothing moves unless you change a number.

Over defined

Two rules disagree, like two different lengths on one edge. The editor shows the conflict so you can remove one.

What's planned

None of this is built yet. Here's what the first versions aim for.

Relations
Coincident, horizontal, vertical, parallel, perpendicular, tangent, equal and symmetric.
Dimensions
Length, distance, angle, radius and diameter. Change a number and the drawing follows.
Curves
Lines, arcs, circles, ellipses and Bézier curves.
Layers
Organize a drawing into layers, with constraints that can reach across them.
Files
Open SVGs, edit them, and export SVGs. Projects save as JSON so your constraints are kept.
Undo
Undo and redo for every change, with Cmd/Ctrl+Z.
